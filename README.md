# PPS-LABS
Programming and problem solving 
Course & Student Details

    Course: Programming for Problem Solving (PPS)
    Program: B.Tech Mechanical Engineering (First Year)
    Institution: MIT World Peace University (MIT-WPU), Pune

Lab Assignments Index
Lab 3: Arithmetic Operations

    Menu-driven C program to perform basic arithmetic operations (addition, subtraction, multiplication, division).

Lab 4: Matrices & Machine Measurement Data

    4(A): Basic matrix operations including the addition of two matrices.
    4(B): Addition of two 2 x 2 matrices representing measurement data of two machine components to display the resultant measurement matrix.

Lab 5: String Operations & Model Comparison

    5(A): Menu-driven C program to perform standard string operations using built-in string functions (string.h).
    5(B): C program to accept two machine model names and verify whether both models match.

Lab 6: Functions & Recursion

    6(A): C function to compute the factorial of a number with recursion.
    6(B): C function to compute the factorial of a number without recursion (iterative approach).

Lab 7: Structures for Mechanical Components

    C program using an array of structures to store and display details of mechanical components (Component ID, weight in kg, and material type).

Lab 8: Pointers & Parameter Passing

    8(A): C function to swap two numbers using pointers (Call by Reference).
    8(B): C function to demonstrate swapping two numbers using Call by Value.
    8(C): Workshop dimension correction program using a user-defined function and pointers to swap accidentally reversed length and width values of a rectangular metal plate.

Lab 9: File Handling

    C program to copy the contents of one file into another file using standard file handling operations.

Lab 10: Calendar Generation

    C program to print the complete month-by-month calendar for the year 1980.

Tools & Environment

    Language: C
    Compiler: GCC
